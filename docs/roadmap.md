- ✅ Rust workspace, крейт `engine-core` (без зависимостей, собирается под WASM)
- ✅ Модель доски и система координат (две позиционные системы, голова/дом/сход)
- ✅ Генерация ходов по правилам ФСНР: правило головы + исключение первого дубля,
  нет битья, запрет полного забора (в т.ч. временного), сброс с перебором,
  обязательность ходов / старшая кость
- ✅ Подсчёт очков (оин/марс), состояние игры, исходы
- ✅ Базовая эвристика + жадный ИИ (1 пол-ход)
- ✅ Варианты: Traditional / Nardegammon / Classic / **Hachapuri** (настраиваемое
  правило головы `head_limit`, исправлено по результатам аудита)
- ✅ Куб удвоений (`cube.rs`): значение/владелец, удвоение, **бивер**
- ✅ Матч и money game (`matchplay.rs`): длины 7/9/11/13/15/17, **Кроуфорд**, **Jacoby**
- ✅ Анализ (`analysis.rs`): вероятности (плейсхолдер), эквити, ранжирование ходов,
  решения по кубу (пас/тайк/тугуд/бивер)
- ✅ Тесты (46 модульных + e2e self-play) и пример `cargo run --example selfplay`
- 🔜 Нотация позиции/партии (Position ID / Match ID), сериализация
- 🔜 Бенчмарки генератора (позиций/сек) — база для оптимизации под WASM

## Фаза 1 — Нейросеть и сила игры

- ✅ Кодировка позиции (`encoding.rs`): TD-Gammon-стиль, фичи на пункт × сторона,
  без бар/ввода, перспектива «сторона у хода» (196 входов)
- ✅ Нейросеть (`net.rs`): MLP 196→hidden→3 (P(вы), P(марс-вы), P(марс-проигрыш)),
  forward на чистом Rust (native+WASM), сериализация весов, semi-gradient TD-шаг
- ✅ Тренировка self-play на чистом Rust (`engine-train`): TD(0), ε-исследование,
  CLI `train`/`bench`. Без Python/ONNX — веса грузятся прямо в WASM-клиент
- ✅ Поиск n-ply expectiminimax (`search.rs`): шанс-узлы по 21 броску + выбор хода;
  усиливает статическую сеть (1–2 ply онлайн, глубже в анализе)
- ✅ Бенчмарк: net vs heuristic / random, alternating colours, win% + ppg
- 🔜 Масштабирование силы: больше игр, бо́льшая сеть, TD(λ) с eligibility traces,
  опц. AlphaZero-стиль (policy+value + MCTS с шанс-узлами)
- 🔜 Точные bearoff/race таблицы (54 264 позиции), усечение роллаутов
- 🔜 Серверные роллауты с понижением дисперсии; метрика ER vs роллауты
- 🔜 Реальные вероятности из сети → точные решения по кубу: live-cube (Janowski)
  и таблица match equity (MWC) для матчевых удвоений (заменяют пороговую модель)

## Фаза 2 — Игра в браузере

- ✅ `engine-wasm` (wasm-bindgen) — крейт-обёртка, веса вшиты, Engine API (JSON);
  собирается под `--target web` и `--target nodejs`; рантайм-проверен (Node smoke)
- ✅ Web Worker + типизированный RPC-клиент (`web/src/engine/`)
- ✅ Vite + Svelte 5 каркас; сборка и `svelte-check` чисты
- ✅ Доска (визуализация, `lib/board/`: координаты + Board.svelte) — базовая
- ✅ **Играбельный цикл против ИИ**: бросок → выбор хода → ответ движка, win%-бар.
- ✅ Экран настройки (`Home.svelte`): выбор варианта (4), силы (1–3 ply), цвета;
  игра за чёрных (движок ходит первым) работает.
- ✅ Инлайн-анализ в игре: ранжирование ходов (win% + потеря эквити) + решение по
  кубу (пас/тайк/тугуд/бивер) для кубовых вариантов.
- ✅ **E2E-харнесс на Playwright** (реальный Chromium): 4 теста — загрузка движка,
  игра против ИИ, анализ, куб-решение, игра за чёрных. Всё зелёное + svelte-check чист.
- ✅ **Живой куб удвоений** (нардегаммон/хачапури): игрок предлагает удвоение →
  движок берёт/пасует по своей оценке; движок сам удваивает → игрок тайк/пас/бивер;
  счёт сессии с множителем куба. Покрыто e2e.
- ✅ **Ходы кликом по доске**: клик шашки → подсветка пунктов назначения → клик;
  цепочки (один ход двумя костями) и выкидывание; список ходов оставлен как запасной.
  Покрыто e2e (полная партия играется кликами).
- ✅ **Матч до N + Кроуфорд**: выбор формата (деньги / до 7/9/11/13/15/17), счёт
  матча, Кроуфорд-партия без куба при счёте «1 до победы», пост-Кроуфорд снова с
  кубом, экран конца матча. Покрыто e2e (формат + играбельность).
- ✅ **Drag-and-drop** шашек (тащишь шашку на пункт назначения; работает вместе с
  кликами) + **анимация**: бросок костей (шейк/масштаб), подсветка последнего хода
  (пульс на изменившихся пунктах), призрак шашки при перетаскивании; учитывается
  `prefers-reduced-motion`. Покрыто e2e (drag-тест).
- 🔜 Плавное «скольжение» шашек точка-в-точку (FLIP/absolute-доска) — полировка
- 🔜 Редактор позиций + глубокий анализ (2–3 ply) на отдельном экране
- 🔜 Relay-режим для спарринга с LogasAI

> **Известное ограничение:** нейросеть обучена на стандартном старте (15 на голове),
> поэтому в **хачапури** (4 на голове) она вне распределения — игра и куб-решения
> там ненадёжны. Нардегаммон/Традиционные/Классика используют стандартный старт и
> играются корректно. Хачапури-сила требует отдельного self-play обучения.
- 🔜 Доска в стиле **Backgammon Studio Heroes**: анимация шашек/костей, стрелки,
  подсветка нелегального забора, темы
- 🔜 Виджет куба в UI (удвоить/тайк/пас/бивер), счёт матча + Кроуфорд
- 🔜 История ходов, перемотка
