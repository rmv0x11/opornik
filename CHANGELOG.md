# Опорник — журнал релизов

Версионирование: SemVer (`MAJOR.MINOR.PATCH`). Версия задаётся в `web/package.json`,
вшивается в сборку (`__APP_VERSION__`) и показывается в подвале меню. Каждый деплой на
GitHub Pages помечается версией в сообщении коммита `gh-pages`. До `1.0.0` —
одиночная игра; `1.0.0` — закрытый чеклист одиночной 1.0; онлайн/аккаунты — `2.0.0`.

Живой сайт: https://rmv0x11.github.io/opornik/

## [0.9.11] — 2026-06-05

### Кнопки действий — в центре доски
- **Бросок, подтверждение хода, предложение/ответ по кубу теперь нажимаются по
  центру доски** и показываются только когда нужно соответствующее действие.
  Кубик «бросок» переехал из боковой панели в центр поля (`🎲 Бросить кости`);
  «Разыграть первый ход», «✓ Подтвердить ход», «⬆ Удвоить», «Тайк / Пас / Бивер»
  — там же. Дубли кнопок в нижней панели убраны.
- **Значения костей после броска по-прежнему показываются сбоку доски** (в правой
  рейке). Контейнер кнопок «прозрачен» для кликов (`pointer-events`) — построение
  хода на доске не перекрывается; «Подтвердить ход» появляется в центре только
  когда ход полностью собран. «Отменить» и «Выкинуть шашку» остаются в панели
  (плюс свайп-вверх для выкида).

### Лист партии — действия с кубом и сохранение
- **В лист партии теперь записываются действия с кубом**: удвоение (с новым
  значением), тайк, пас, бивер — отдельными строками (🎲²), у каждой свой игрок и
  номер хода.
- **Лист партии можно сохранить** — кнопка «📄 Скачать лист» скачивает читаемый
  `.txt`-транскрипт (шапка матча, все ходы с костями/оценками, действия с кубом,
  пипсы) **и копирует его в буфер обмена**.

### Анимация
- Центральные кнопки появляются с мягким «pop» (back-ease); кубик-«бросок» дышит
  и слегка потряхивает кости, приглашая бросить; всё уважает
  `prefers-reduced-motion`.
- Исправлены неопределённые токены веса шрифта (`--fw-semi`/`--fw-bold`) — раньше
  `font:`-шорткаты с ними молча сбрасывались на обычный вес.

## [0.9.10] — 2026-06-05

### Обзор лучших ходов (Оценка)
- **Обзор лучших ходов теперь всегда на виду.** Раньше список лучших ходов

## [0.9.9] — 2026-06-04

### Лист партии / обзор ходов (доводка)
- **Вернул удобный обзор ходов.** В 0.9.6–0.9.8 ради «страница не прокручивается»
  лист партии ужимался в крошечную полосу (~1–2 строки), и из-за этого обзор
  лучших ходов (альтернативы + эквити + «переиграть») был тесным и неудобным.
  Теперь лист партии снова в **просторном прокручиваемом блоке** (как было до
  0.9.6): обзор читается комфортно, список прокручивается внутри себя, а страница
  прокручивается по необходимости. Доска на старте по-прежнему высокая
  (заполняет экран), в партии — чуть ниже. e2e-тесты обновлены: проверяют
  просторность и прокрутку листа партии и читаемость обзора альтернатив.

## [0.9.8] — 2026-06-04

### Совместимость (iPhone / Safari)
- **Исправлена загрузка движка на iPhone (Safari/WebKit).** Сафари отвергал
  `WebAssembly.instantiateStreaming` с ошибкой «Unexpected response MIME type.
  Expected 'application/wasm'» — даже когда Content-Type корректный
  (`application/wasm`). Это баг WebKit (особенно в Web Worker); из-за того что MIME
  как раз правильный, встроенный fallback wasm-bindgen не срабатывал и ошибка
  пробрасывалась → приложение падало на айфоне (на Android/Chrome всё работало, их
  `instantiateStreaming` мягче). Теперь воркер грузит WASM **байтами** и
  инстанцирует через `WebAssembly.instantiate` (без проверки MIME) — работает во
  всех браузерах. Проверено в Playwright WebKit и Chromium (движок грузится без
  ошибок).

## [0.9.7] — 2026-06-04

### Лист партии (фикс 0.9.6)
- **Починена прокрутка листа партии на телефоне.** В 0.9.6 список ходов был внутри
  `<details>` с `display:flex` — браузер оборачивает контент `<details>` в
  отдельный бокс, из-за чего `flex` на списке не работал: список не сжимался,
  обрезался и **не прокручивался** (неюзабельно). Переписал лист партии на обычный
  `<div>` со сворачиванием по кнопке — теперь список **надёжно прокручивается
  внутри себя** (≈4–6 строк видно, остальное скроллом), а страница по-прежнему не
  прокручивается. Кросс-браузерно (не зависит от `::details-content`).
- **Добавлены e2e-тесты юзабельности** (мобильный вьюпорт 390×844): лист партии
  прокручивается внутри себя и страница не скроллится; сворачивание/разворачивание
  работает. Плюс упрочнён общий тест-хелпер хода (ретраит при переходной
  перерисовке, не бросает ход на полпути).

## [0.9.4] — 2026-06-04

### Игра и движок
- **Передвижение фишек — точный разбор для всех порядков ходов.** Движок отдаёт
  все легальные **упорядоченные** последовательности под-ходов (`legalSequences`),
  и интерфейс строит ход, сопоставляя выбранное как префикс этих
  последовательностей. Каждая последовательность легальна на **каждом**
  промежуточном шаге (правило головы, занятые пункты, запрет транзитного прайма,
  перебор при выкиде). Это закрывает целый класс багов разбора, который оставался
  при сопоставлении по мультимножеству: теперь можно сыграть **младшую кость
  первой** к той же клетке, корректно обрабатываются транзитный прайм, старшая
  кость и порядок выкидывания. Покрыто юнит- и e2e-тестами (включая
  рандомизированный property-тест на 600 позициях).
- **Розыгрыш первого хода (ФСНР) — без повторного броска.** Первый ход играется
  **теми же двумя костями** розыгрыша (по одной от каждого игрока); кто выбросил
  больше — ходит первым. Повторного броска нет; при равенстве — переброс (только
  для определения очерёдности). Дальше каждый бросает свои две кости как обычно.

### Доска
- Убрана центральная **горизонтальная** полоса: ряды сходятся напрямую, делителем
  служит вертикальная планка по центру (как на настоящей доске).
- Кости (после броска и приглашение к броску), лоток сброса и метка «дом» вынесены
  в **боковую панель справа** — кости больше не по центру доски.

## [0.9.1] — 2026-06-04

### Движок
- **Expert (3-ply) теперь с жёстким лимитом перебора (leaf-budget)**: глубокие узлы
  «обрезаются» до статической оценки после исчерпания бюджета, кандидаты в корне
  ранжируются от лучших — поэтому лучшие ходы сохраняют полную глубину. Худший
  случай в WASM упал с **~23с до ~0.8с** на busy-дубле (форвард-прунинг top-8/12
  один не спасал из-за полной нижней плай). Сила не пострадала (бюджет тратится на
  топ-кандидатов; ply≤2 без изменений).

## [0.9.0] — 2026-06-04 — single-player release candidate

Первый именованный релиз. Одиночная игра против движка — функционально полная.

### Движок
- Полные правила ФСНР: правило головы (+ исключение первого дубля), нет битья,
  запрет полного прайма (в т.ч. транзитного), сброс с перебором, старшая кость.
- Нейросеть (TD-self-play, 196→hidden→3) + n-ply expectiminimax. 3 уровня (1–3 ply).
- **Эксперт (3-ply) ограничен по времени**: forward-pruning топ-8 кандидатов на
  глубоких узлах — худший случай ~1.5с вместо зависаний.
- Куб удвоений на модели **Janowski** (gammon-aware точки тайка/каша/удвоения),
  матчи, Кроуфорд, бивер, оин/марс.

### Игра и UI
- Доска: треугольные пункты, **темы доски и фишек** (Изумруд/Классик/Полночь +
  мраморные наборы), адаптив (телефон), кости с точками.
- **Розыгрыш первого хода (ФСНР)**: в начале партии каждый бросает одну кость, кто
  больше — ходит первым (при равенстве — переброс); первый игрок затем бросает свои
  две кости как обычно.
- Ходы: клик/драг, **перетаскивание сразу на конечную клетку**, бросок по центру
  доски, **выкид свайпом вверх**, подтверждение/возврат хода.
- Анализ: оценка ходов (эквити + win%), **лист партии**, **ревью истории +
  переигровка** (даже после подтверждения), решения по кубу.
- Сдача (оин только когда марс невозможен / марс), **сохранение/импорт партий**.

### Анимация
- Compositor-only скольжение фишки (transform + подъём/посадка), **выкид по дуге в
  лоток**, тумблинг костей + пружинное приземление, win-бар scaleX + count-up,
  кроссфейд экранов, каскад строк анализа. Строгий `prefers-reduced-motion`.

### Дизайн
- High-end система токенов (тёплая палитра, многослойные тени, бевелы), AA-контраст.

### Известные ограничения
- Хачапури: сеть вне распределения (нужна отдельная тренировка).
- Classic: ничья последним броском не реализована (TODO).
- Редкий edge-case разбора хода (транзитный прайм при перестановке под-ходов).
